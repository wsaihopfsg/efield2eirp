Mathematical Breakdown (ANSI C63.10) f = 13.56 MHz

1. Transition Boundary (dnearfield) 3.519 m
λ = c / f = 2.998×10⁸ / 13.56×10⁶ ≈ 22.11 m
dnearfield = λ / (2π) = 22.11 / (2 × 3.14159) = 3.519 m
2. Distance Correction Formula -11.84 dB
Correction = -40·log₁₀(3.52 / 3.0) - 20·log₁₀(10.0 / 3.52)
= -2.77 dB (near-field 40dB/dec) + (-9.07 dB far-field 20dB/dec) = -11.84 dB
3. Extrapolated Electric Field (E-field) 67.03 dBµV/m
FSlimit = FSmax + Correction = 78.87 + (-11.84) = 67.03 dBµV/m
4. Free-space Wave Impedance Conversion (Z₀) -51.53 dB
Z₀ = 120π ≈ 376.73 Ω → 20·log₁₀(377) = 51.53 dBΩ
H (dBµA/m) = E (dBµV/m) - 51.53 dB = 67.03 - 51.53 = 15.50 dBµA/m
Standard Reference Summary
  • Near-Field (d < 3.52 m): Magnetic dipole decay follows inverse-cube power, yielding a roll-off of 40 dB/decade.
  • Far-Field (d ≥ 3.52 m): Plane wave radiation follows inverse-distance, yielding a roll-off of 20 dB/decade.
  • ETSI & FCC Alignment: Conversion between E and H is normalized with free space intrinsic impedance ($377\ \Omega$).
